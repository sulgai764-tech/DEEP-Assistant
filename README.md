<h1>DEEP Assistant</h1>

Персональный ИИ-ассистент в терминале для Windows.

<h2>Возможности</h2>

- Бесплатный ИИ через Cloudflare Workers AI
- Автоофлайн: переключение на локальный ИИ (Ollama) при отсутствии интернета
- Голосовое управление (Ctrl+G или команда "голос")
- Открытие программ, папок, файлов по естественной команде
- Поиск в интернете с анализом источников
- Перевод текста
- Цветной интерфейс с темами оформления
- Погода в любом городе
- Заметки с редактированием и удалением
- Просмотр локального и внешнего IP
- Быстрый доступ к избранным программам (list)
- Сворачивание в системный трей
- Веб-интерфейс для доступа с телефона
- Сохранение истории диалогов
- Автозагрузка при старте Windows
- Логирование ошибок и диалогов
- Автоматическая проверка обновлений

<h2>Установка</h2>

<h3>Способ 1: Установщик Setup.exe</h3>

1. Запустите DEEP_Assistant_Setup.exe
2. Выберите путь установки
3. Отметьте нужные галочки (ярлык, автозагрузка, Win+R)
4. Нажмите "Установить"

<h3>Способ 2: Ручная установка</h3>

1. Скопируйте папку DEEP_Assistant в C:\
2. Скопируйте deep_команда.bat в C:\Windows\
3. Запустите install.bat от имени Администратора
4. Переименуйте config.example.txt в config.txt
5. Впишите ключи Cloudflare в config.txt
6. Запустите запуск.bat

<h2>Получение ключей Cloudflare</h2>

1. Зарегистрируйтесь на dash.cloudflare.com
2. AI → Workers AI → Use REST API
3. Скопируйте Account ID
4. Профиль → API Tokens → Create Token → Workers AI → Read
5. Скопируйте токен в config.txt

CF_ACCOUNT_ID=ваш_account_id
CF_API_TOKEN=ваш_api_token

<h2>Команды</h2>

- help — список команд
- clear — очистить экран
- exit — выход
- update — обновление
- reload — перезапуск
- list — избранные программы
- голос или Ctrl+G — голос
- свернись — в трей
- автозагрузка — вкл/откл
- theme — темы (classic, amber, matrix, ocean)
- time — дата и время
- ver — версия
- ip — IP-адреса
- погода — погода в Москве
- погода Город — погода в городе
- заметка текст — сохранить
- заметки — показать
- измени заметку 3 текст — изменить
- удали заметку 3 — удалить
- очистить заметки — удалить все
- открой хром — открыть программу
- найди запрос — поиск
- переведи текст — перевод
- любой вопрос — нейросеть

<h2>Доступ с телефона</h2>

Запустите сервер.bat, откройте IP-адрес из окна в браузере телефона.

<h2>Требования</h2>

- Windows 10/11
- Python 3.11+
- Микрофон (для голоса)

<h1>Решение проблем</h1>

<h2>Окно сразу закрывается</h2>

Откройте cmd от имени Администратора и введите:

```
cd C:\DEEP_Assistant
python deep_assistant.py
```
Прочитайте ошибку.

<h2>Python не найден</h2>

Установите Python 3.11+ с python.org. 
При установке обязательно поставьте галочку Add Python to PATH.

<h2>Не хватает библиотек</h2>

Запустите install.bat от имени Администратора. Или вручную:

```
python -m pip install requests duckduckgo-search deep-translator SpeechRecognition pyttsx3 pystray pillow keyboard flask
```

<h2>ИИ не отвечает</h2>

• Проверьте ключи Cloudflare в config.txt
• Убедитесь что CF_ACCOUNT_ID из 32 символов, а CF_API

<h2>pip не является внутренней или внешней командой</h2>

Устанавливайте библиотеки через python -m pip:
```
python -m pip install название_библиотеки
```

<h2>Не хватает библиотек (ModuleNotFoundError)</h2>

Запустите install.bat от имени Администратора. Если не помогло, установите вручную:
```
python -m pip install requests duckduckgo-search deep-translator SpeechRecognition pyttsx3 pystray pillow keyboard flask speedtest-cli
```

Если ошибка прав доступа, добавьте флаг --user:

```
python -m pip install --user requests duckduckgo-search deep-translator SpeechRecognition pyttsx3 pystray pillow keyboard flask
```

<h2>Ошибка ModuleNotFoundError: No module named 'ddgs'</h2>

Установите новую версию duckduckgo-search:

```
python -m pip install ddgs
```

Или используйте старый импорт в modules/ai.py:

```
from ddgs import DDGS
```

замените на 

```
from duckduckgo_search import DDGS.
```
<h2>Ошибка latin-1 codec cant encode</h2>

Исправлено в текущей версии. Все спецсимволы автоматически заменяются на безопасные. Запускайте ассистент через запуск.bat — он переключает кодировку консоли на UTF-8.

<h2>ИИ не отвечает или пишет ошибку</h2>

• Проверьте интернет-соединение
• Проверьте ключи Cloudflare в config.txt: CF_ACCOUNT_ID из 32 символов, CF_API_TOKEN начинается с cfut_
• Убедитесь что AI_PROVIDER=cloudflare написано без кавычек и лишних пробелов
• Если ключи верные, но ошибка сохраняется — создайте новый токен в Cloudflare

<h2>Не работает микрофон или голосовое управление</h2>

• Проверьте что микрофон подключён: ПКМ по динамику в трее → Звуки → вкладка Запись
• В настройках Windows: Конфиденциальность → Микрофон → доступ включён
• Закройте другие программы которые используют микрофон: Discord, Zoom, Skype, OBS
• Попробуйте команду голос вместо Ctrl+G

<h2>Телефон не подключается к веб-серверу</h2>

• ПК и телефон должны быть в одной Wi-Fi сети
• Откройте брандмауэр Windows: Win+R → wf.msc → Правила для входящих подключений → Создать правило → Порт → TCP → 5050 → Разрешить
• Если адрес начинается с 127.0.0.1, он не откроется на телефоне. Нужен адрес вида 192.168.x.x

<h2>Автозагрузка не работает</h2>

• Запустите запуск.bat от имени Администратора и выберите пункт 2
• Или в ассистенте введите команду автозагрузка
• Проверьте реестр: Win+R → regedit → HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run → должна быть строка DEEP_Assistant
• Не переносите папку DEEP_Assistant после включения автозагрузки

<h2>Не работает обновление через команду update</h2>

• Проверьте интернет-соединение
• Убедитесь что GitHub не заблокирован провайдером
• Проверьте строку GITHUB_REPO в config.txt
• Если не работает — скачайте новую версию вручную с GitHub

<h2>Ассистент отвечает медленно</h2>

• Первый запрос после запуска может идти до 10 секунд — модель загружается
• При отсутствии интернета переключается на Ollama (если установлен)
• Проверьте скорость интернета

<h2>Python 3.14 не работает с библиотеками</h2>

Установите Python 3.11 или 3.12. Не все библиотеки поддерживают версию 3.14.

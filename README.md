                 DEEP Assistant

Персональный ИИ-ассистент в терминале для Windows.

                  Возможности

- Бесплатный ИИ через Cloudflare Workers AI
- Голосовое управление (Ctrl+G)
- Открытие программ, папок, файлов
- Поиск в интернете с анализом источников
- Перевод текста
- Быстрый доступ к избранным программам (list)
- Сворачивание в системный трей
- Веб-интерфейс для доступа с телефона
- Сохранение истории диалогов
- Автозагрузка при старте Windows

                      Установка

1. Скопируйте папку DEEP_Assistant в C:\
2. Скопируйте deep_команда.bat в C:\Windows\
3. Запустите install.bat от имени Администратора
4. Переименуйте config.example.txt в config.txt и впишите ключи Cloudflare
5. Запустите запуск.bat

                 Получение ключей Cloudflare

1. Зайдите на dash.cloudflare.com и зарегистрируйтесь
2. Слева выберите AI - Workers AI -  REST API (Тут сразу будет и Account ID) - Create a Workers AI API Token
3. Нажмите на иконку профиля - My Profile - API Tokens - Create Token
4. Выберите Workers AI - Read, нажмите Continue to summary - Create Token
5. Скопируйте токен (начинается с cfut_) и вставьте в config.txt:

CF_ACCOUNT_ID=ваш_account_id
CF_API_TOKEN=ваш_api_token

                         Команды

- help - список команд
- открой хром - открыть программу
- найди погоду - поиск в интернете
- переведи текст - перевод
- list - избранные программы
- голос или Ctrl+G - голосовой ввод
- свернись - свернуть в трей

                       Доступ с телефона

Запустите сервер.bat, откройте IP-адрес из окна в браузере телефона.

                          Требования

- Windows 10/11
- Python 3.11+
- Микрофон (для голоса)
